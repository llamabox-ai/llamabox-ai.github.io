# LlamaBox

**Private offline AI chat for Android** — on-device GGUF inference with llama.cpp.

🌐 **Site:** [https://llamabox-ai.github.io/](https://llamabox-ai.github.io/)  
📋 **Waitlist:** [https://llamabox-ai.github.io/waitlist.html](https://llamabox-ai.github.io/waitlist.html)  
📦 Package: `com.llamabox` · Android 7.0+ arm64  
✉️ Commercial: [aalhad.dev@gmail.com](mailto:aalhad.dev@gmail.com)

## Why it exists

Cloud AI requires trust. LlamaBox runs the model on your phone so privacy is **architecture**, not a promise.

- No cloud inference  
- No accounts  
- No telemetry  
- Vision + TTS + model hub  
- CPU today (GPU roadmap, honest)
