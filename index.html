FAQ

Questions, answered cleanly.

Citable facts for humans — and for answer engines via schema + llms.txt.

What is LlamaBox?
LlamaBox is a free Android app that runs AI chat entirely on your phone. It loads GGUF models via llama.cpp and generates tokens on-device — no cloud, no accounts, no data collection. Multimodal vision is supported with compatible models.
Does LlamaBox need internet?
No for chat once a model is installed. Optional network is only for downloading models from public hubs.
Is my data private?
Yes. Prompts, chats, and images stay on-device. No server, no account, no telemetry. Privacy is structural.
What models can I run?
Any GGUF that fits RAM. Prefer Q4_K_M. Small models (e.g. Qwen2.5 0.5B, SmolLM2 360M) suit mid-range phones. Vision needs base + mmproj (e.g. Gemma 3 4B Vision).
Can it analyze images?
Yes with a vision-capable model. Photo or gallery → local encoder (CPU) → text answer. Keeps the UI from freezing under GPU contention.
Does it use the GPU?
CPU-only today. GPU OpenCL is planned with diagnostics and fallback — we will not ship a decorative GPU switch.
Is it free / open source?
Dual-licensed: AGPL-3.0 + commercial. “LlamaBox” is a reserved trademark. Public source lands when closed beta ends. Commercial: aalhad.dev@gmail.com.
What Android versions?
Android 7.0 (API 24)+, arm64-v8a. iOS is a future target.
